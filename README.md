# Chaord Marketplace

Chaord Marketplace is a public Claude Code plugin marketplace from [Chaord](https://chaord.ai), providing plugins for personal AI infrastructure and workflow.

## Plugins

- [experiment-conductor](./plugins/experiment-conductor/README.md) provides Researcher and Executor agents that run GPU-cluster experiments with you in the loop, keeping a lab record that survives across sessions.
